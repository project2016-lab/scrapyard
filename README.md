# Summary
Scratch (.sb3) robot-building battle game: build robot from parts, fight players, earn parts currency, cloud matchmaking, co-op

# Details
wants a Scratch .sb3 game: build your own robot from starting inventory parts (wheels, mountable guns, wires with rope physics, cannons, lasers), press a done button, then fight other players' machines
winning earns parts (currency) used to buy higher quality gear (stronger non-breaking wires, stronger metals/alloys, guided missiles, etc.); payout depends on the parts on the opponent's robot
components have properties: steel has hardness, gears have efficiency, wires have strength, etc.
wants co-op and multiplayer with cloud matchmaking to play against people online
supplied exampleProject.sb3 containing all Scratch extensions and blocks as a reference
